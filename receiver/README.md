# 天空日記：夕陽摘要接收端（老師設定一次就好）

學生的「天空日記觀察站」在**學生與家長都勾選同意**後，每天傍晚送一份夕陽摘要到你的 Google 雲端硬碟：

- 一張太陽軌跡圖縮圖（JPEG，200 KB 以內）
- 幾個數字：照片張數、第一次／最後看到太陽的時間、太陽在畫面中的位置、17:00 的天空顏色
- 暱稱（12 字以內，程式會擋電話號碼與 email）、班級代碼（選填）、縣市

**不收**：姓名、原始照片、電腦名稱、IP、檔案路徑。Apps Script 也拿不到送出者的 IP。

## 設定步驟（約 10 分鐘）

1. 在 Google 雲端硬碟新增一份試算表，命名「天空日記_夕陽摘要」。
2. 試算表選單「擴充功能 → Apps Script」，把編輯器裡原本的程式全部刪掉，貼上同資料夾的 `Code.gs`，按存檔。
3. 編輯器右上角「部署 → 新增部署作業」→ 左邊齒輪選「網頁應用程式」：
   - 說明：天空日記接收端
   - 執行身分：**我**
   - 誰可以存取：**所有人**（學生的程式不必登入 Google 才能送）
4. 按「部署」，第一次會要求授權（存取試算表與雲端硬碟），照畫面允許。
5. 複製「網頁應用程式網址」（`https://script.google.com/macros/s/……/exec`）。
6. 把網址貼到瀏覽器網址列，應該看到一行字：`天空日記夕陽摘要接收端運作中`。
7. 把這個網址貼回給 Claude，由它填進觀察站程式並重新發布。

## 收到的資料在哪裡

- 試算表「summaries」工作表：一台相機一天一列（同一天重送會覆蓋那一列），最後一欄是圖片連結。
- 雲端硬碟「天空日記_收件」資料夾：每台相機一個子資料夾（縣市_暱稱_裝置代碼前 6 碼），裡面一天一張圖。
- 選單「天空日記 → 重新整理統計」會產生「各縣市」彙總。

## 停用

「部署 → 管理部署作業 → 封存」立刻停止接收。資料直接在試算表刪列、刪資料夾即可。

## 修改程式後要更新

「部署 → **管理部署作業**」→ 選目前的部署 → 鉛筆（編輯）→ 版本選「新版本」→ 部署。
**不要**按「新增部署作業」，那會產生新網址，學生的程式就送不到了。

## 安全說明

網址會寫在學生的程式裡，等於是公開的。接收端只收格式完全正確的資料（欄位多一個就拒收、圖片必須是 200 KB 以內的 JPEG、縣市必須在 22 縣市清單內），但擋不住有人照格式偽造。若發現奇怪的資料，先封存部署，再請 Claude 換網址。

測試一律用本機假物件：`node test_receiver.js`。不要對正式網址送測試資料。
